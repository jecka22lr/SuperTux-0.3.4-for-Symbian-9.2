SuperTux 2 (SuperTux 0.3.4) for S60 3rd Edition - split install

Only needed if a phone refuses the all-in-one SuperTux2 .sisx.
Install these in this order, all to the SAME drive (the memory card is best):

  1. 1_SuperTux2_program.sisx   (also installs the Nokia Open C runtimes if needed)
  2. 2_SuperTux2_data1.sisx, 2_SuperTux2_data2.sisx, 2_SuperTux2_data3.sisx,
     2_SuperTux2_data4.sisx

Self-signed: set App. mgr. > Options > Settings > Software installation to "All" first.
To uninstall, remove "SuperTux 2" and the four "SuperTux 2 data" entries in App. mgr.
