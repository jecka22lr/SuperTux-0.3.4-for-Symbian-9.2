Community add-ons shipped with the SuperTux 0.3.4 S60v3 port
=============================================================
All GPL 2(+) / CC-by-sa 3.0. Each zip is a 0.3.x add-on (levels + an .nfo).
The game mounts every zip in <install drive>:\resource\apps\supertux2\addons\;
they show up under Contrib Levels and can be switched off in Options > Add-ons.

Changes for the port
  ctdabomb-worldmaps: music/worldmap_tux.ogg (gone since 0.1.x) -> music/salcon.ogg
    in the Penny worldmap, 4.6-icy mud, 10-lastnight, 13-owltemple and CT's
    snow-log, snow-city, snow-high, final-snomans.
  mantis-valley: NewIcelevel3/4 platforms/pedestral.sprite -> pedestal.sprite,
    platforms/icesquare1.sprite -> sawblade/icesquare1.sprite.
  Collection zips leave out images identical to stock 0.3.4, editor files
    (.xcf, *~, Thumbs.db) and images no level uses.
  Known harmless: the Penny and Mantis Valley tilesets name tiles/pipe/blueh.png,
    which never existed; the engine uses its dummy texture and no level uses
    those tiles.
